# Лабораторная работа №1: Первичное исследование и оценка качества данных

## Описание проекта
Данная работа посвящена первичному обзору и аудиту качества данных на примере датасета банковского маркетинга. В ходе работы проводится анализ структуры данных, выявление пропусков, дубликатов и аномалий, а также разведочный анализ (EDA) для формирования гипотез.

## Цель работы
Научиться описывать датасет в терминах задач ИАД, проводить базовый аудит качества и строить осмысленные визуализации.

## Структура репозитория
* `data/` — исходный датасет (bank.csv).
* `notebooks/` — воспроизводимый Jupyter Notebook (`01_data_understanding.ipynb`) с кодом и анализом.
* `report/` — краткий текстовый отчёт (`quality_report.md`) с выводами и планом улучшения.
* `README.md` — описание проекта и инструкции.
