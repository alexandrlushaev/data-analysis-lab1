# Лабораторная работа №1: Первичное исследование и оценка качества данных

## Описание проекта
Данная работа посвящена первичному обзору и аудиту качества данных на примере датасета банковского маркетинга. [cite_start]В ходе работы проводится анализ структуры данных, выявление пропусков, дубликатов и аномалий, а также разведочный анализ (EDA) для формирования гипотез[cite: 2, 5, 8].

## Цель работы
[cite_start]Научиться описывать датасет в терминах задач ИАД, проводить базовый аудит качества и строить осмысленные визуализации[cite: 3, 4, 12].

* [cite_start]`notebooks/` — воспроизводимый Jupyter Notebook (`01_data_understanding.ipynb`) с кодом и анализом[cite: 34, 133].
* [cite_start]`report/` — краткий текстовый отчёт (`quality_report.md`) с выводами и планом улучшения[cite: 36, 134].
