Отчёт о качестве данных
1. Введение

Датасет: Bank Marketing Dataset (Маркетинговые кампании банка). Источник: UCI Machine Learning Repository / Kaggle. Размер: 11 162 × 17 (строки × столбцы). 


Предметная область: Банковский сектор, анализ эффективности прямых продаж через телефонный маркетинг. 


Условный заказчик: Аналитический отдел банка или команда по оптимизации CRM. 


Возможные задачи ИАД: 


Классификация: Предсказание того, согласится ли клиент на открытие депозита (целевой признак deposit). 


Сегментация: Выявление групп клиентов с похожим финансовым поведением для персонализации звонков. 


Описательная аналитика: Определение факторов, которые сильнее всего влияют на успех сделки.
