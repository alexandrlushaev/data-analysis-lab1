# Отчёт о качестве данных по проекту "Bank Marketing"

## 1. Введение
* **Объект исследования:** Данные маркетинговых кампаний банка.
* **Заказчик:** Маркетинговый департамент.
* **Цель:** Оценить готовность данных для построения модели предсказания подписки на депозит.

## 2. Паспорт датасета
| Признак | Тип данных | Описание |
| :--- | :--- | :--- |
| **age** | int64 | Возраст клиента |
| **job** | object | Сфера занятости (есть значения unknown) |
| **balance** | int64 | Среднегодовой баланс на счету |
| **duration** | int64 | Длительность последнего контакта в сек. |
| **deposit** | object | Целевая переменная (yes/no) |

## 3. Таблица выявленных проблем
| № | Тип проблемы | Описание | Потенциальный риск | Решение |
| :--- | :--- | :--- | :--- | :--- |
| 1 | Неявные пропуски | Значения "unknown" в `job` и `education` | Неточный портрет клиента | Замена на моду (частое значение) |
| 2 | Выбросы | Возраст > 75 лет, баланс > 50 000 | Искажение средних величин | Обработка по методу IQR |
| 3 | Типы данных | Месяц и день контакта — это строки/числа | Нельзя считать сезонность | Конвертация в формат Datetime |
| 4 | Асимметрия | Перекос данных в признаке `balance` | Ошибки линейных моделей | Логарифмическое преобразование |
| 5 | Масштаб | Разброс баланса (тысячи) и возраста (десятки) | Доминирование баланса в модели | Стандартизация (StandardScaler) |

## 4. План улучшения качества
1. **Критично:** Удалить дубликаты и заполнить "unknown" в категориальных полях.
2. **Важно:** Провести фильтрацию выбросов по балансу, чтобы исключить аномально богатых клиентов, не являющихся типичными.
3. **Желательно:** Выполнить масштабирование признаков перед этапом моделирования.

## 5. Краткое резюме
В ходе работы я научился проводить первичный аудит: от поиска дубликатов до математического выявления выбросов. Главный вывод: данные требуют серьезной предобработки категорий (профессия и образование), так как они имеют ключевое значение для бизнес-задачи, но содержат много неопределенности.
